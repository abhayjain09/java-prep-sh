# java-advanced/

**Status:** Not started — coming in Module 2 (File System APIs) and Module 3 (Multithreading & Concurrency), with JVM internals (Module 11) added later.

Planned coverage:
- File System APIs: `java.io`, `java.nio`, `java.nio.file`, `Path`, `Files`, `WatchService`, ZIP/CSV/JSON/XML handling, streaming I/O, serialization, file locks, large-file processing — applied to the Order/Inventory domain (e.g. bulk order import/export, inventory snapshot files).
- Multithreading & Concurrency: `Executors`, `CompletableFuture`, Locks, Atomic classes, concurrent collections, Virtual Threads, deadlocks, race conditions — applied to concurrent stock reservation and order processing.
- JVM internals: memory model, GC, class loading, JIT, profiling with JFR/JMC, JMH benchmarking.

See the root [README.md](../README.md) for the full module roadmap and current progress.
